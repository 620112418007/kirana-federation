# สหพันธรัฐแห่งคีรันนา: ชุดไฟล์สำหรับ GitHub Pages

เกมกระดานการเมืองและเศรษฐกิจแห่งคีรันนา เล่นกับ AI เรียนกติกาในโหมดสอนเล่น หรือชวนเพื่อนเล่นออนไลน์ ทั้งหมดอยู่ในหน้าเว็บนิ่งหน้าเดียว ไม่ต้องมีเซิร์ฟเวอร์ของตัวเอง

กติกาค่าเริ่มต้นคือฉบับ 0.4.4: เกม 12 รอบ ยุคละ 3 รอบ ทุกรัฐวางแรงงานและจ้างแรงงานพร้อมกัน แรงงานยืนอยู่ที่เดิมข้ามรอบ สิ่งปลูกสร้างทำงานเองเมื่อโครงการของมันมีแรงงานเต็ม การปฏิรูปเปิดดูกองทหารกับกองพักแล้วทิ้งได้ 1 ใบ จากนั้นสับกองพักกับการ์ดใหม่รวมเข้ากองทหาร การ์ดทหารที่ได้มาใหม่ทุกทางเข้ากองทหารทันที บุกเบิกชนะได้สินค้าเท่าผลผลิตของการ์ดและสิทธิ์ผนวกดินแดนด้วยต้นทุนลด 2 เหมือนเดิม โจมตีชนะปล้นครึ่งหนึ่งของสินค้าที่ค้างบนโครงการเป้าหมาย ปัดขึ้น ภาระผู้นำหักเฉพาะการนับคะแนนที่สามอันดับแรกมีรัฐเสมอกัน จุดเปลี่ยนกระแส 5 เมื่อเล่น 4 รัฐ และแผงทุกรัฐมีตัวนับสัญลักษณ์อุดมการณ์ห้าสี ฉบับ 0.4.4 ใช้ตารางการ์ดทหารของผู้ออกแบบ กองเสื้อคลุมน้ำเงินอ่อนลง เพลงชาติให้ความชอบธรรม 2 ชาตินิยมให้ 1 เมื่อชนะบุกเบิก รัฐบาลทหารให้ 1 เมื่อชนะการโจมตีรัฐอื่น และการทูตเลือกได้ว่าจะสับกองพักทหารกลับเข้ากองทหารหรือเก็บไว้ เกมที่บันทึกไว้จากฉบับก่อนยังเล่นต่อด้วยกติกาเดิมของมัน ตั้งแต่ 11 พ.ย. 2026 ผู้เล่นเลือกโหมดทดลอง **รัฐที่แตกแยก (Asymmetric)** ได้ตอนตั้งโต๊ะหรือตอนสร้างห้องออนไลน์ ทุกรัฐได้การ์ดผู้สนับสนุนที่ให้ความสามารถเฉพาะตัว

หน้าตาเกมเป็นเมืองยุคปฏิวัติอุตสาหกรรมแบบกอธิค: แผ่นเหล็กหล่อตอกหมุดทองเหลือง แสงตะเกียงแก๊ส กระจกสีประจำยุค การ์ดกระดาษเก่า เฟืองทองเหลืองนับรอบ และระฆังโบสถ์ตีบอกยุคใหม่ ฟอนต์ Taviraj, IBM Plex Sans Thai และ UnifrakturMaguntia โหลดจาก Google Fonts ถ้าโหลดไม่ได้ เกมใช้ฟอนต์ไทยของเครื่องแทน

## ตั้งค่าครั้งแรก

1. สร้าง repository ใหม่บน GitHub แบบ **Public** ตั้งชื่ออะไรก็ได้ เช่น `federation`
2. อัปโหลดไฟล์ในโฟลเดอร์นี้ขึ้นคลัง (ลากวางทั้งโฟลเดอร์ผ่านหน้าเว็บได้) จากนั้นสร้างไฟล์ workflow บน GitHub: กด **Add file > Create new file** พิมพ์ชื่อ `.github/workflows/records.yml` แล้ววางเนื้อหาจากไฟล์ `workflow/records.yml` ในโฟลเดอร์นี้ลงไป กด Commit (GitHub รัน workflow จากตำแหน่ง `.github/workflows` เท่านั้น ส่วนสำเนาในโฟลเดอร์ `workflow` ลบทิ้งได้หลังสร้างเสร็จ)
3. ไปที่ **Settings > Pages** ช่อง Source เลือก **Deploy from a branch** เลือก `main` กับ `/ (root)` แล้วกด Save
4. ไปที่ **Settings > Actions > General** หัวข้อ Workflow permissions เลือก **Read and write permissions** แล้วกด Save ระบบบันทึกต้องเขียนไฟล์ในโฟลเดอร์ `data`
5. รอหนึ่งถึงสองนาที เกมจะอยู่ที่ `https://ชื่อผู้ใช้.github.io/ชื่อคลัง/`

## ลงชื่อเข้าใช้ Google (ต้องมีจึงบันทึกเกมได้)

ผู้เล่นต้องลงชื่อเข้าใช้ Google ก่อน เกมจึงบันทึกให้เล่นต่อได้ และชัยชนะจึงเข้าหอเกียรติยศ ยังไม่ลงชื่อก็เล่นได้ทุกโหมด แต่ปิดหน้าแล้วเกมหาย ตั้งค่าครั้งเดียวดังนี้

1. เปิดหน้า **Clients** ของ Google Cloud Console (`console.developers.google.com/auth/clients` อยู่ในหมวด **Google Auth Platform**) สร้างโปรเจกต์ใหม่หรือเลือกโปรเจกต์ที่มี
2. หน้า **Branding** กรอกชื่อแอปกับอีเมลติดต่อ หัวข้อ **App domain** ช่อง **Application home page** ใส่ที่อยู่หน้าเกม (`https://ชื่อผู้ใช้.github.io/ชื่อคลัง/`) ช่อง **Application privacy policy link** ใส่ที่อยู่เดียวกันตามด้วย `privacy.html` แล้วกด Save (Google ไม่ยอมให้กด Publish app จนกว่าจะมีสองช่องนี้) หน้า **Audience** เลือกผู้ใช้แบบ **External** แล้วกด **Publish app** (ถ้าค้างไว้ที่ Testing จะลงชื่อได้เฉพาะบัญชีที่เพิ่มเป็น test user) เกมใช้แค่ขอบเขตพื้นฐาน email, profile, openid ไม่ต้องเพิ่มขอบเขตอื่น
3. กลับหน้า **Clients** กด **Create client** เลือกชนิด **Web application** ช่อง **Authorized JavaScript origins** ใส่ `https://ชื่อผู้ใช้.github.io` (มีแค่ https กับชื่อโดเมน ไม่มีชื่อคลังหรือ / ต่อท้าย) แล้วกด Create
4. คัดลอก Client ID (ลงท้ายด้วย `.apps.googleusercontent.com`) เปิดไฟล์ `config.js` บน GitHub กดรูปดินสอ ใส่ไว้ในเครื่องหมายคำพูด แล้ว Commit:
   ```js
   googleClient: 'ใส่ Client ID ตรงนี้',
   ```
   Client ID ไม่ใช่ความลับ ใส่ในคลังสาธารณะได้

สิ่งที่เกมเก็บ: แฮชของรหัสบัญชี Google กับชื่อต้น ไว้ในเบราว์เซอร์ของผู้เล่นเอง และไม่ส่งให้ผู้เล่นคนอื่น ถ้าตั้งหอเกียรติยศอัตโนมัติไว้ ตอนลงชื่อเข้าใช้หน้าเกมส่งโทเค็นการลงชื่อไปให้สคริปต์ของเจ้าของเกมหนึ่งครั้ง สคริปต์ตรวจกับ Google แล้วเก็บแค่แฮชของรหัสบัญชี ไม่เก็บอีเมล การลงชื่อเข้าใช้ใช้ได้เฉพาะหน้าเว็บที่ต้นทางตรงกับที่ลงทะเบียนไว้ ไฟล์ที่เปิดจากเครื่อง (`file://`) จึงลงชื่อไม่ได้

**เครื่องผู้พัฒนา** บันทึกเกมได้โดยไม่ต้องลงชื่อเข้าใช้ ปลดล็อกครั้งเดียวต่อเบราว์เซอร์ที่ **ตั้งค่า > รหัสผู้พัฒนา** ในหน้าเกมเก็บไว้แค่แฮชซ้อนสองชั้นของรหัส อ่านซอร์สแล้วก็ไม่ได้รหัส ใช้ได้ทั้งหน้าเว็บ ไฟล์ในเครื่อง และหน้าอาร์ติแฟกต์ ถ้าทำรหัสหาย ขอรหัสใหม่แล้วแก้ค่า `DEV_HASH` ใน `index.html`

**หลังบ้านของผู้พัฒนา** ตัวเลือกชุดกฎ (ฉบับ 0.4.4 ค่าเริ่มต้น โหมดทดลองรัฐที่แตกแยกที่ทุกรัฐจั่วการ์ดผู้สนับสนุน 5 ใบเลือก 1 ฉบับ 0.4.3 ฉบับ 0.4.2 ที่ภาระผู้นำหักทุกการนับ ฉบับ 0.4.1 ฉบับ 0.4 ที่ปฏิรูปทิ้งได้เฉพาะกองพัก ฉบับ 0.4 ปฏิรูปตรวจพล ฉบับ 0.3 ตัวแปรจุดเปลี่ยน 5 ของฉบับ 0.3 และฉบับ 0.2) ห้องผู้ออกแบบที่จำลอง AI หลายเกม หัวข้อข้อที่หน้าเกมตีความกฎเอง รายการความต่างของฉบับ 0.3 และบรรทัดชุดกฎกับซีดในหน้าตั้งค่าระหว่างเกม ขึ้นเฉพาะแท็บที่เข้าระบบผู้พัฒนา ผู้เล่นทั่วไปเลือกได้สองโหมด คือปกติ (ฉบับ 0.4.4) และรัฐที่แตกแยก (Asymmetric) ที่เปิดให้ทุกคนตั้งแต่ 11 พ.ย. 2026

**เข้าสู่ระบบและออกจากระบบแยกต่อแท็บ** ทุกบัญชีมีโปรไฟล์ผู้นำ เกมที่บันทึก และตั๋วหอเกียรติยศของตัวเอง (เก็บใต้ `u.รหัสบัญชี` ในเบราว์เซอร์) แท็บใหม่เริ่มด้วยบัญชีที่ลงชื่อล่าสุดในเบราว์เซอร์นั้น ปุ่ม **ออกจากระบบ** มีทั้งบัญชี Google และบัญชีผู้พัฒนา กดแล้วมีผลเฉพาะแท็บนั้น แท็บอื่นเล่นต่อตามเดิม เครื่องที่ปลดล็อกแล้วมีปุ่ม **เข้าระบบผู้พัฒนา** ให้กดกลับเข้าได้ทันที บัญชีแรกที่ลงชื่อในเบราว์เซอร์หนึ่งรับโปรไฟล์เดิมของเบราว์เซอร์นั้นไป บัญชีถัดไปเริ่มตั้งผู้นำใหม่ของตัวเอง ผู้เยี่ยมชมใช้โปรไฟล์ร่วมของเบราว์เซอร์ แต่ได้ตัวตนออนไลน์ใหม่ทุกแท็บ สองแท็บที่ไม่ได้ลงชื่อบัญชีเดียวกันจึงเป็นผู้เล่นคนละคนเสมอ

ข้อจำกัด: ทุกการตรวจทำในเบราว์เซอร์ของผู้เล่น จึงเป็นกติกาบ้านที่คนแก้ไฟล์หน้าเว็บเองข้ามได้ ถ้าต้องการบังคับจริงต้องมีเซิร์ฟเวอร์ที่ตรวจโทเค็นของ Google

## หอเกียรติยศอัตโนมัติ ลานความคิดเห็น และสถิติการเล่น (Google Sheet + Apps Script)

ตั้งครั้งเดียว แล้วผู้ชนะที่ลงชื่อเข้าใช้จะขึ้นหอเกียรติยศเองตอนจบเกม ความคิดเห็นที่กดส่งขึ้นลานทันที เครื่องผู้พัฒนาลบรายชื่อหรือความคิดเห็นจากหน้าเกมได้ และสคริปต์เริ่มเก็บสถิติการเล่นให้ผู้พัฒนาดู ไม่ต้องเปิด GitHub ทุกคนที่เปิดหน้าหอเกียรติยศเห็นทันที

1. สร้าง Google Sheet ใหม่ใน Google Drive ตั้งชื่ออะไรก็ได้ เช่น `หอเกียรติยศ สหพันธรัฐ`
2. ในชีต กด **Extensions > Apps Script** ลบโค้ดตัวอย่าง แล้ววางเนื้อหาทั้งหมดจาก `scripts/hof-apps-script.gs` ใส่ Client ID ตัวเดียวกับใน `config.js` ที่บรรทัด `GOOGLE_CLIENT_ID` แล้วกดบันทึก (รูปแผ่นดิสก์)
3. กด **Deploy > New deployment** เลือกชนิด **Web app** ช่อง Execute as เลือก **Me** ช่อง Who has access เลือก **Anyone** แล้วกด Deploy
4. Google ขอสิทธิ์ให้สคริปต์ (อ่านเขียนชีตนี้ และเรียก Google เพื่อตรวจการลงชื่อ) ถ้าขึ้นว่า Google hasn't verified this app ให้กด **Advanced > Go to … (unsafe)** เพราะเป็นสคริปต์ของคุณเอง แล้วกด Allow
5. คัดลอก **Web app URL** (ลงท้ายด้วย `/exec`) ไปใส่ใน `config.js` ที่ `hofEndpoint` แล้ว Commit ลองเปิด URL นั้นในเบราว์เซอร์ ต้องเห็น `{"ok":true,"app":"kirana-federation-hof",...}`

การดูแล: บันทึกอยู่ในชีตชื่อ `hof` ความคิดเห็นอยู่ในชีต `cmt` รายการที่ผู้พัฒนาลบอยู่ในชีต `removed` จำนวนคนเข้าต่อวันอยู่ในชีต `daily` และเกมที่เล่นอยู่ในชีต `games` (สคริปต์สร้างชีตเองเมื่อใช้ครั้งแรก) ลบแถวในชีต `hof` หรือ `cmt` เพื่อเอาออกได้ทันทีเหมือนเดิม บัญชีหนึ่งส่งได้ไม่เกิน 20 บันทึกและ 30 ความคิดเห็นต่อวัน สคริปต์สร้างทุกช่องใหม่เอง ตรวจว่าคะแนนสุทธิเท่าความชอบธรรมลบตราบาป และผู้ชนะไม่ต่ำกว่าคู่แข่ง เวลาของความคิดเห็นมาจากสคริปต์ ไม่มีใครลงวันที่ล่วงหน้าเพื่อค้างไว้บนสุดได้ ถ้าแก้โค้ดสคริปต์ภายหลัง ต้อง **Deploy > Manage deployments > แก้ไข > Version: New version** ที่อยู่ URL จะคงเดิม

สคริปต์รุ่น 11 พ.ย. 2026 ใช้กติกาหอเกียรติยศชุดใหม่ (หัวข้อหอเกียรติยศด้านล่าง) ถ้าตั้งสคริปต์รุ่นก่อนไว้แล้ว ให้วางโค้ดใหม่ทับแล้วทำ New version เสร็จแล้วเปิด Web app URL ต้องเห็น `"v":4` ระหว่างที่ยังไม่ได้อัปเดต หน้าเกมก็ซ่อนบันทึกที่กติกาไม่นับและเรียงลำดับใหม่เองอยู่แล้ว ต่างกันแค่สคริปต์รุ่นเก่ายังรับบันทึกเหล่านั้นเข้าชีต และส่งรายชื่อ 30 อันดับแรกตามคะแนนอย่างเดียว

ถ้าเคยตั้งสคริปต์รุ่นก่อน (รุ่นที่มีแต่หอเกียรติยศ) ไว้แล้ว: เปิด Apps Script ของชีตเดิม ลบโค้ดเก่าทั้งหมด วางเนื้อหาใหม่จาก `scripts/hof-apps-script.gs` ใส่ Client ID ที่ `GOOGLE_CLIENT_ID` เหมือนเดิม กดบันทึก แล้วทำ New version ตามย่อหน้าก่อน ลานความคิดเห็น ปุ่มลบ และสถิติการเล่นจะใช้ได้กับที่อยู่ URL เดิม

## สถิติการเล่น (เห็นเฉพาะผู้พัฒนา)

เมื่อ `config.js` มีที่อยู่สคริปต์ หน้าเกมส่งสถิติให้สคริปต์ตัวเดียวกัน ผู้เล่นทั่วไปไม่เห็นข้อมูลชุดนี้ และไม่มีที่อยู่สาธารณะใดเปิดให้อ่าน

- **จำนวนคนเข้าต่อวัน** เบราว์เซอร์หนึ่งส่งสัญญาณวันละครั้ง สคริปต์บวกยอดของวันนั้นในชีต `daily` แยกสมาชิก (ลงชื่อเข้าใช้ตอนเข้า) กับผู้มาเยือน และนับเครื่องผู้พัฒนาไว้อีกช่อง สคริปต์ไม่เก็บรายการการเข้าชม
- **เกมที่เล่น** ทุกเกมที่เริ่ม จบ หรือออกกลางคัน เป็นหนึ่งแถวในชีต `games` มีโหมด ชุดกฎ จำนวนรัฐ ระดับ AI รอบที่ไปถึง เวลาที่เล่น คะแนนตอนจบ การ์ดวิจัยและการ์ดทหารที่แต่ละรัฐเลือก (แยกผู้เล่นกับ AI) รหัสสุ่มของเบราว์เซอร์ และแฮชของรหัสบัญชีถ้าเป็นสมาชิก
- **บันทึกการเล่น** แถวของเกมที่จบหรือออกกลางคันเก็บบันทึกการเดิน (ซีดกับทุกการตัดสินใจของผู้เล่น) พอให้เล่นเกมนั้นซ้ำได้ทั้งเกม

ดูสถิติได้ที่ **เมนู > สถิติผู้เล่น** บนเครื่องผู้พัฒนา หน้านั้นมีจำนวนคนเข้าวันนี้ เฉลี่ยต่อวัน และรายวัน เกมที่เริ่ม เล่นจบ ออกกลางคัน คนที่เล่นจบแยกสมาชิกกับผู้มาเยือน การ์ดวิจัยและการ์ดทหารที่ถูกเลือกมากที่สุดในแต่ละชุดกฎ (นับจากเกมที่เล่นจบ) และรายการเกมล่าสุด ปุ่ม **ดูเกม** สร้างเกมนั้นขึ้นใหม่จากบันทึกการเดินแล้วเล่นถึงตอนจบ หรือหยุดตรงที่ผู้เล่นออกไป ระหว่างดูไม่มีอะไรถูกบันทึกหรือส่งเพิ่ม เปิดชีตใน Google Sheets ดูข้อมูลดิบได้เช่นกัน

สถิติไม่มีอีเมล ไม่มีชื่อบัญชี และสคริปต์ไม่เห็นที่อยู่ IP ผู้เล่นปิดการส่งได้ที่ **ตั้งค่า > ส่งสถิติการเล่น** และเบราว์เซอร์ที่ส่งสัญญาณ Global Privacy Control หรือ Do Not Track จะไม่ส่งอะไรเลย แถวของเกมที่เก่ากว่า 365 วันถูกลบตอนผู้พัฒนาเปิดหน้าสถิติ (ปรับที่ `KEEP_DAYS`) ตั้ง `STATS: false` ในสคริปต์เพื่อหยุดเก็บทั้งหมด หัวข้อ 5 ของ `privacy.html` บอกผู้เล่นเรื่องนี้ไว้ ถ้าเปลี่ยนสิ่งที่เก็บ ให้แก้นโยบายตามด้วย

ข้อจำกัด: สคริปต์ยืนยันได้ว่าผู้ส่งเป็นบัญชี Google จริงหรือเครื่องผู้พัฒนา แต่ยืนยันไม่ได้ว่าเกมเล่นจริง คนที่เขียนโปรแกรมเองยังส่งบันทึกปลอมที่ผ่านการตรวจได้ เจ้าของเกมจึงยังต้องคอยดูชีต ปุ่มส่งผ่าน GitHub ยังใช้ได้เมื่อไม่ได้ตั้งที่อยู่นี้ หรือเมื่อส่งออนไลน์ไม่สำเร็จ

## ผู้เล่นออนไลน์และความยากของ AI

- ปุ่ม **ออนไลน์ N คน** มุมล่างซ้าย (มุมขวาบนระหว่างเล่น) เปิดรายชื่อทุกคนที่เปิดหน้าเกมอยู่ ทั้งสมาชิกที่ลงชื่อเข้าใช้และผู้เยี่ยมชม พร้อมสิ่งที่แต่ละคนทำอยู่ ระบบนี้ใช้ห้องล็อบบี้เดียวกับการเล่นออนไลน์ เบราว์เซอร์จึงต่อรีเลย์ Nostr และต่อตรงกับเบราว์เซอร์อื่นด้วย WebRTC ซึ่งทำให้เครื่องที่ต่อกันเห็นที่อยู่เครือข่ายของกันและกัน ผู้เล่นปิดได้ที่ **ตั้งค่า > แสดงตัวว่าออนไลน์**
- ตอนตั้งโต๊ะเลือก **ความยาก AI** ได้สามระดับ: **ง่าย** AI พลาดบ่อย ชัยชนะไม่ขึ้นหอเกียรติยศ **ปกติ** แบบเดิม **ยาก** AI ไม่ลังเล และได้ความชอบธรรม 2 ทุกต้นยุคจากบารมีตระกูลเก่า (ขึ้นในบันทึกเกมและป้ายที่มาของคะแนน) ผู้ชนะระดับนี้ขึ้นหอเกียรติยศก่อนระดับอื่น ในห้องออนไลน์ผู้สร้างห้องเลือกระดับให้ที่นั่ง AI
- ปุ่ม AI แนะนำ มีเฉพาะในโหมดสอนเล่น เกมกับ AI และเกมออนไลน์ไม่มีตัวช่วยจาก AI
- ตอนตั้งโต๊ะเลือก **โหมด** ได้สองแบบ: **ปกติ** และ **รัฐที่แตกแยก (Asymmetric)** ซึ่งยังเป็นโหมดทดลอง ก่อนเริ่มเกมทุกรัฐจั่วการ์ดผู้สนับสนุน 5 ใบ เลือกเก็บ 1 ใบ แล้วได้ความสามารถเฉพาะตัวไปทั้งเกม การ์ดทั้ง 30 ใบอยู่ในหน้าวิธีเล่น เกมออนไลน์ใช้โหมดที่ผู้สร้างห้องเลือก ห้องในล็อบบี้และแถวในหอเกียรติยศของโหมดนี้มีชื่อโหมดกำกับ

## เล่นออนไลน์กับเพื่อน

1. ส่งลิงก์หน้าเกมให้เพื่อน ทุกคนกรอกชื่อผู้นำ ตั้งชื่อรัฐหรือปล่อยให้สุ่มชื่ออัลธาลานี และวาดธงรัฐ
2. คนหนึ่งเข้า **เล่นออนไลน์กับเพื่อน** แล้วกด **สร้างห้องใหม่** จากนั้นส่งรหัสห้อง หรือกด **คัดลอกลิงก์ชวนเพื่อน**
3. เพื่อนกดเข้าห้องจากรายการห้อง หรือกรอกรหัส เข้าห้องแล้วกด **นั่งที่นี่** บนเก้าอี้ว่างหนึ่งตัว (ผู้สร้างห้องนั่งเก้าอี้ตัวแรกให้เอง) ย้ายเก้าอี้หรือกด **ลุกจากที่นั่ง** ได้จนกว่าเกมเริ่ม ผู้สร้างห้องกด **ทอยลูกเต๋าและเริ่มเกม** ที่นั่งที่ยังว่างให้ AI เล่นแทน คนที่ยังยืนอยู่ได้ดูเกม
4. ระหว่างเกมกดปุ่ม **แชท** มุมบนเพื่อคุยกัน

เบื้องหลัง: เบราว์เซอร์ของผู้เล่นหาเจอกันผ่านรีเลย์ Nostr สาธารณะ แล้วต่อตรงกันด้วย WebRTC ทุกเครื่องรันเอนจินเดียวกันจากซีดเดียวกัน และส่งกันเฉพาะคำตอบของผู้เล่นคน ผลเกมจึงตรงกันทุกเครื่อง

- **ถ้ามีคนหลุด** เกมรอ 20 วินาที แล้วให้ AI เล่นแทนที่นั่งนั้น เมื่อเขาเปิดหน้าเกมใหม่ เมนูจะมีปุ่ม **กลับเข้าห้องออนไลน์** กดแล้วเครื่องจะขอบันทึกเกมจากเพื่อน เล่นย้อนให้ทัน แล้วได้ที่นั่งคืน
- **ห้องถูกลบทันทีที่ผู้เล่นคนสุดท้ายออก** ผู้เล่นคนสุดท้ายที่กดออกจากห้องเห็นคำเตือนก่อน ออกแล้วบันทึกห้องในเครื่องถูกลบ และเบราว์เซอร์อื่นในล็อบบี้ที่เคยเล่นห้องนั้นลบปุ่ม **กลับเข้าห้องออนไลน์** ของห้องนั้นตามทันที ใครกดกลับเข้าห้องที่ไม่มีผู้เล่นเหลือแล้ว จะเห็นว่าห้องปิดแล้วและบันทึกถูกลบ ข้อยกเว้นเดียวคือเบราว์เซอร์ที่หลุดไปเองไม่ถึงนาทีครึ่ง เช่น กดรีเฟรชหรือเน็ตสะดุด ซึ่งยังเล่นต่อจากบันทึกในเครื่องได้ ส่วนการกดออกจากห้องเองไม่เข้าข้อยกเว้นนี้
- **ระหว่างรอผู้สร้างห้อง** หน้าห้องบอกว่าส่งคำทักไปกี่ครั้งและต่อกับผู้เล่นในห้องได้กี่คน เครื่องส่งคำทักซ้ำทุกสองวินาทีครึ่งจนผู้สร้างห้องตอบ คำขอนั่งก็ส่งซ้ำจนรายชื่อที่นั่งยืนยัน ผู้สร้างห้องส่งรายชื่อที่นั่งให้ทุกคนทุกห้าวินาที ถ้ารอนานมีปุ่ม **เชื่อมต่อใหม่** คนที่หลุดก่อนเริ่มเกมยังได้เก้าอี้คืนถ้ากลับมาภายใน 20 วินาที
- **บัญชีเดียวนั่งได้ที่เดียว** บัญชีเดียวกันเปิดห้องจากสองหน้าต่าง ที่นั่งย้ายไปอยู่กับหน้าต่างล่าสุด ถ้าเป็นบัญชีของผู้สร้างห้องเอง หน้าต่างที่สองถูกปฏิเสธพร้อมคำอธิบาย ให้ออกจากระบบในแท็บนั้นเพื่อเข้าแบบผู้เยี่ยมชม
- **รีเลย์** เกมใช้รีเลย์ Nostr 8 ตัวที่ตรวจแล้วว่าตอบภายในราวสองวินาที (8 พ.ย. 2026) เปลี่ยนชุดรีเลย์ได้ที่ `relays` ใน `config.js` โดยไม่ต้องแก้ `index.html` ทุกเครื่องต้องใช้ชุดเดียวกันจึงจะเจอกัน
- **ถ้าเชื่อมต่อไม่ได้** เครือข่ายบางแห่ง เช่น เครือข่ายบริษัท มหาวิทยาลัย หรือมือถือบางค่าย กั้นการต่อตรงแบบ WebRTC ทางแก้คือใช้ TURN server (มีบริการฟรีแบบจำกัดปริมาณ เช่น Cloudflare และ Open Relay ของ Metered) แล้วใส่ค่าที่ `turn` ใน `config.js`:
  ```js
  turn: [{ urls: 'turn:ที่อยู่:3478', username: 'ชื่อ', credential: 'รหัส' }],
  ```
  หรือใส่แท็ก `<meta name="fed-turn" content='[...]'>` ใน `<head>` ของ `index.html` แบบเดิมก็ได้
- **ทดสอบคนเดียวสองแท็บ** เปิดหน้าเกมสองแท็บ ให้แท็บหนึ่งลงชื่อเข้าใช้ (หรือเข้าระบบผู้พัฒนา) อีกแท็บกด **ออกจากระบบ** สองแท็บจะเป็นผู้เล่นคนละคน ทดสอบแบบไม่ต่อรีเลย์ได้ด้วย `index.html?net=local` สองแท็บในเบราว์เซอร์เดียวกัน ซึ่งคุยกันผ่าน BroadcastChannel

## หอเกียรติยศและลานความคิดเห็น

- กติกาหอเกียรติยศ (11 พ.ย. 2026): เกมกับ AI ขึ้นหอได้เฉพาะโต๊ะ 4 รัฐที่ AI ระดับปกติหรือยาก ชัยชนะกับ AI ระดับง่ายหรือที่โต๊ะ 3 รัฐไม่ขึ้นหอ การเรียงให้ผู้ชนะที่เล่นกับ AI ระดับยากขึ้นก่อน จากนั้นจึงเรียงตามคะแนนสุทธิ เกมออนไลน์ที่ไม่มีที่นั่ง AI เลยเรียงตามคะแนนร่วมกับเกมที่ AI ระดับปกติ บันทึกเก่าที่กติกาไม่นับยังอยู่ในชีตหรือไฟล์ แต่หน้าเกมไม่แสดง
- จบเกมแล้ว ถ้าผู้ชนะเป็นผู้เล่น (ไม่นับ AI และโหมดสอนเล่น) และลงชื่อเข้าใช้แล้ว ผลจะบันทึกในเครื่อง ส่งให้ผู้เล่นที่ออนไลน์อยู่ และขึ้นหอเกียรติยศอัตโนมัติทันทีถ้าตั้งไว้ตามหัวข้อด้านบน หน้าจบเกมไม่ขึ้นข้อความว่าบันทึกแล้ว จะมีข้อความเฉพาะตอนที่ผู้เล่นต้องลงชื่อเข้าใช้หรือส่งซ้ำ บันทึกมีคะแนน จำนวนการ์ดวิจัย การ์ดทหาร และโครงการ พร้อมการวิเคราะห์ว่ารัฐนั้นเล่นสายใด ซึ่งอ่านจากแอคชันที่เลือก การ์ดนวัตกรรม และการ์ดวัฒนธรรมตลอดเกมเทียบกับโต๊ะทั่วไปของฉบับ 0.4.4 ห้าแกน (นักขยายดินแดน พาณิชย์ ทหาร วิทยาการ ศาสนา) แกนหลักคู่กับแกนรองมีชื่อระบอบของตัวเอง และคำนำหน้าแนวธุรกิจหรือราชวงศ์ของผู้นำเปลี่ยนชื่อเรียกบางแบบ หอเกียรติยศเรียกทุกบันทึกด้วยชื่อชุดปัจจุบัน บันทึกที่จบก่อนเปลี่ยนชื่อใช้ผลอ่านเดิมกับชื่อชุดใหม่ ชี้ที่ชื่อเพื่อดูชื่อตอนจบเกม
- ปุ่ม **ส่งเข้าหอเกียรติยศถาวรผ่าน GitHub** เปิดหน้า New issue ที่กรอกข้อมูลไว้แล้ว ผู้ส่งต้องล็อกอิน GitHub แล้วกด Submit Action จะตรวจข้อมูล เพิ่มลง `data/hall-of-fame.json` ตอบกลับ แล้วปิด issue หน้าเกมอ่านไฟล์นี้จาก `raw.githubusercontent.com` จึงเห็นภายในไม่กี่นาที
- **ลานความคิดเห็น** กดส่งแล้วความคิดเห็นขึ้นลานทันที หน้าเกมไม่เปิดหน้าอื่นและไม่ขึ้นข้อความใด เมื่อตั้งสคริปต์ตามหัวข้อด้านบนแล้ว สคริปต์เก็บความคิดเห็นไว้ให้ทุกคนที่เปิดลานภายหลังเห็น ผู้เขียนต้องลงชื่อเข้าใช้ Google (หรือเป็นเครื่องผู้พัฒนา) ผู้เยี่ยมชมเห็นปุ่มลงชื่อเข้าใช้แทนช่องเขียน ถ้าส่งไม่สำเร็จ ใต้ช่องเขียนจึงบอกสาเหตุพร้อมปุ่มส่งอีกครั้ง ถ้ายังไม่ได้ตั้งสคริปต์ ความคิดเห็นอยู่ในเบราว์เซอร์ของผู้เขียนและถึงผู้เล่นที่ออนไลน์อยู่ตอนนั้นเท่านั้น
- ผู้เขียนให้ดาว 1 ถึง 5 ดวงได้หรือไม่ให้ก็ได้ ความคิดเห็นที่ไม่ได้ให้ดาวไม่ขึ้นดาว หัวลานแสดงดาวเฉลี่ยโดยนับดาวล่าสุดของแต่ละคนครั้งเดียว ความคิดเห็นที่ผ่านสคริปต์นับตามบัญชี เพราะสคริปต์เป็นผู้ติดป้ายผู้เขียนเอง
- **ผู้พัฒนาลบรายการได้** บนเครื่องผู้พัฒนา ทุกแถวในหอเกียรติยศและทุกความคิดเห็นมีปุ่ม **ลบ** กดแล้วเกมถามยืนยันก่อน ลบรายชื่อแล้วรายชื่อถัดไปเลื่อนขึ้นแทน สคริปต์ลบแถวในชีตและจดรายการนั้นไว้ในชีต `removed` ทุกหน้าเกมที่อ่านสคริปต์จึงซ่อนรายการนั้นด้วย แม้รายการจะยังอยู่ในไฟล์ `data` ของคลังหรือค้างอยู่ในเบราว์เซอร์ของผู้เล่น บันทึกที่ถูกลบซึ่งส่งเข้ามาซ้ำจะไม่กลับขึ้นมา ถ้ายังไม่ได้ตั้งสคริปต์ การลบซ่อนรายการได้เฉพาะในเครื่องผู้พัฒนา ส่วนการลบให้ทุกคนต้องแก้ไฟล์ `data/hall-of-fame.json` หรือ `data/comments.json` บน GitHub
- ระบบในคลังยังรับ issue ที่ชื่อขึ้นต้น `[HOF]` และ `[COMMENT]` เหมือนเดิม ลิงก์ที่เกมสร้างไม่ใส่ป้าย label เพราะ GitHub เปิดหน้านั้นเป็น 404 ให้ผู้ที่ไม่มีสิทธิ์ติดป้าย หน้าเกมไม่สร้าง issue ของความคิดเห็นแล้ว

## อัปเดตเกมรุ่นใหม่

อัปโหลดทับเฉพาะ `index.html`, `flag-icons.js`, โฟลเดอร์ `assets`, `README.md` และไฟล์ใน `scripts` หรือ `LICENSES` ที่เปลี่ยน ถ้าใส่ Client ID หรือที่อยู่หอเกียรติยศใน `config.js` บนคลังแล้ว อย่าอัปโหลด `config.js` ว่างทับ **ห้ามอัปโหลดโฟลเดอร์ `data` ทับ** เพราะไฟล์ในคลังเก็บหอเกียรติยศและความคิดเห็นจริงไว้ ส่วนในเครื่องเป็นไฟล์ว่าง

## ข้อควรรู้

- **ความเป็นส่วนตัว** เกมจำผู้เล่นด้วยรหัสสุ่มที่เก็บในเบราว์เซอร์ หน้าเว็บนิ่งอ่าน IP ของผู้เล่นไม่ได้ และการเก็บ IP ไว้ในคลังสาธารณะจะเปิดเผยตัวผู้เล่น ข้อมูลที่ออกจากเครื่องมีเพียงชื่อผู้นำ ชื่อรัฐ สี ธง และรหัสแบบแฮช
- **ความไว้ใจ** ระบบออกแบบสำหรับเล่นกับเพื่อน ทุกเครื่องถือสถานะเกมเต็ม คนที่เปิด devtools จึงดูลำดับกองทหารของคนอื่นได้ และบันทึกหอเกียรติยศปลอมแปลงได้ เจ้าของคลังลบรายการที่ไม่ต้องการออกจาก `data/hall-of-fame.json` ได้ตลอด
- **โดเมนของตัวเอง** ถ้าไม่ได้ใช้ที่อยู่ `github.io` ให้บอกเกมว่าคลังชื่ออะไร ด้วย `<meta name="fed-repo" content="ชื่อผู้ใช้/ชื่อคลัง">` และถ้า branch หลักไม่ได้ชื่อ `main` ให้เพิ่ม `<meta name="fed-branch" content="ชื่อ branch">`
- **เกมบันทึกเองอัตโนมัติเมื่อลงชื่อเข้าใช้แล้ว** ปิดหน้าไปกลางเกมแล้วกลับมากด **เล่นต่อ** ในเมนูได้ ระบบเล่นคำตอบที่บันทึกไว้ย้อนจนถึงจุดเดิม บันทึกแยกตามบัญชี คนละบัญชีบนเบราว์เซอร์เดียวกันไม่เห็นเกมของกัน
- **ภาพฉากหลัง** เป็นภาพของเจ้าของเกม ถ้าภาพใดไม่ใช่ผลงานของตัวเองหรือที่จ้างวาด ตรวจสิทธิ์การเผยแพร่ก่อนอัปโหลดขึ้นคลังสาธารณะ
