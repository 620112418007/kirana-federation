# สหพันธรัฐ แห่งคีรันนา: ชุดไฟล์สำหรับ GitHub Pages

เกมกระดานการเมืองและเศรษฐกิจแห่งคีรันนา เล่นกับ AI เรียนกติกาในโหมดสอนเล่น หรือชวนเพื่อนเล่นออนไลน์ ทั้งหมดอยู่ในหน้าเว็บนิ่งหน้าเดียว ไม่ต้องมีเซิร์ฟเวอร์ของตัวเอง

## ในโฟลเดอร์นี้มีอะไร

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวเกมทั้งไฟล์: เอนจิน AI โหมดสอนเล่น หน้าวิธีเล่น และระบบออนไลน์ |
| `data/hall-of-fame.json` | หอเกียรติยศถาวร |
| `data/comments.json` | ลานความคิดเห็นถาวร |
| `workflow/records.yml` กับ `scripts/records.js` | ระบบตรวจและบันทึกผลที่ส่งเข้ามาทาง Issue (ไฟล์ workflow ต้องย้ายไปไว้ที่ `.github/workflows/records.yml` ตามขั้นที่ 2) |
| `LICENSES/trystero-MIT.txt` | สัญญาอนุญาตของ Trystero ไลบรารีเชื่อมต่อแบบเพียร์ทูเพียร์ที่ฝังอยู่ใน index.html |
| `.nojekyll` | บอก GitHub Pages ให้เสิร์ฟไฟล์ตามที่เป็น |

## ตั้งค่าครั้งแรก

1. สร้าง repository ใหม่บน GitHub แบบ **Public** ตั้งชื่ออะไรก็ได้ เช่น `federation`
2. อัปโหลดไฟล์ในโฟลเดอร์นี้ขึ้นคลัง (ลากวางทั้งโฟลเดอร์ผ่านหน้าเว็บได้) จากนั้นสร้างไฟล์ workflow บน GitHub: กด **Add file > Create new file** พิมพ์ชื่อ `.github/workflows/records.yml` แล้ววางเนื้อหาจากไฟล์ `workflow/records.yml` ในโฟลเดอร์นี้ลงไป กด Commit (GitHub รัน workflow จากตำแหน่ง `.github/workflows` เท่านั้น ส่วนสำเนาในโฟลเดอร์ `workflow` ลบทิ้งได้หลังสร้างเสร็จ)
3. ไปที่ **Settings > Pages** ช่อง Source เลือก **Deploy from a branch** เลือก `main` กับ `/ (root)` แล้วกด Save
4. ไปที่ **Settings > Actions > General** หัวข้อ Workflow permissions เลือก **Read and write permissions** แล้วกด Save ระบบบันทึกต้องเขียนไฟล์ในโฟลเดอร์ `data`
5. รอหนึ่งถึงสองนาที เกมจะอยู่ที่ `https://ชื่อผู้ใช้.github.io/ชื่อคลัง/`

## เล่นออนไลน์กับเพื่อน

1. ส่งลิงก์หน้าเกมให้เพื่อน ทุกคนกรอกชื่อผู้นำ ตั้งชื่อรัฐหรือปล่อยให้สุ่มชื่ออัลธาลานี และวาดธงรัฐ
2. คนหนึ่งเข้า **เล่นออนไลน์กับเพื่อน** แล้วกด **สร้างห้องใหม่** จากนั้นส่งรหัสห้อง หรือกด **คัดลอกลิงก์ชวนเพื่อน**
3. เพื่อนกดเข้าห้องจากรายการห้อง หรือกรอกรหัส ผู้สร้างห้องกด **ทอยลูกเต๋าและเริ่มเกม** ที่นั่งที่ยังว่างให้ AI เล่นแทน
4. ระหว่างเกมกดปุ่ม **แชท** มุมบนเพื่อคุยกัน

เบื้องหลัง: เบราว์เซอร์ของผู้เล่นหาเจอกันผ่านรีเลย์ Nostr สาธารณะ แล้วต่อตรงกันด้วย WebRTC ทุกเครื่องรันเอนจินเดียวกันจากซีดเดียวกัน และส่งกันเฉพาะคำตอบของผู้เล่นคน ผลเกมจึงตรงกันทุกเครื่อง

- **ถ้ามีคนหลุด** เกมรอ 20 วินาที แล้วให้ AI เล่นแทนที่นั่งนั้น เมื่อเขาเปิดหน้าเกมใหม่ เมนูจะมีปุ่ม **กลับเข้าห้องออนไลน์** กดแล้วเครื่องจะขอบันทึกเกมจากเพื่อน เล่นย้อนให้ทัน แล้วได้ที่นั่งคืน
- **ถ้าเชื่อมต่อไม่ได้** เครือข่ายบางแห่ง เช่น เครือข่ายบริษัท มหาวิทยาลัย หรือมือถือบางค่าย กั้นการต่อตรงแบบ WebRTC ทางแก้คือใช้ TURN server (มีบริการฟรีแบบจำกัดปริมาณ เช่น Cloudflare และ Open Relay ของ Metered) แล้วใส่ค่าใน `<head>` ของ `index.html`:
  ```html
  <meta name="fed-turn" content='[{"urls":"turn:ที่อยู่:3478","username":"ชื่อ","credential":"รหัส"}]'>
  ```
- **ทดสอบคนเดียวสองแท็บ** เปิด `index.html?net=local&ns=a` กับ `index.html?net=local&ns=b` ในเบราว์เซอร์เดียวกัน สองแท็บจะเป็นผู้เล่นคนละคนและคุยกันผ่าน BroadcastChannel

## หอเกียรติยศและลานความคิดเห็น

- จบเกมแล้ว ถ้าผู้ชนะเป็นผู้เล่น (ไม่นับ AI และโหมดสอนเล่น) ผลจะบันทึกในเครื่อง และส่งให้ผู้เล่นที่ออนไลน์อยู่ทันที บันทึกมีคะแนน จำนวนการ์ดวิจัย การ์ดทหาร และโครงการ พร้อมการวิเคราะห์ว่ารัฐนั้นเล่นสายใด ซึ่งอ่านจากแอคชันที่เลือกตลอดเกมเทียบกับโต๊ะทั่วไป
- ปุ่ม **ส่งเข้าหอเกียรติยศถาวรผ่าน GitHub** เปิดหน้า New issue ที่กรอกข้อมูลไว้แล้ว ผู้ส่งต้องล็อกอิน GitHub แล้วกด Submit Action จะตรวจข้อมูล เพิ่มลง `data/hall-of-fame.json` ตอบกลับ แล้วปิด issue หน้าเกมอ่านไฟล์นี้จาก `raw.githubusercontent.com` จึงเห็นภายในไม่กี่นาที
- ลานความคิดเห็นทำงานแบบเดียวกัน ด้วย issue ที่ชื่อขึ้นต้น `[COMMENT]`
- ระบบจับ issue จากคำนำหน้าชื่อ `[HOF]` และ `[COMMENT]` ลิงก์ที่เกมสร้างจึงไม่ใส่ป้าย label เพราะ GitHub เปิดหน้านั้นเป็น 404 ให้ผู้ที่ไม่มีสิทธิ์ติดป้าย

## ข้อควรรู้

- **ความเป็นส่วนตัว** เกมจำผู้เล่นด้วยรหัสสุ่มที่เก็บในเบราว์เซอร์ หน้าเว็บนิ่งอ่าน IP ของผู้เล่นไม่ได้ และการเก็บ IP ไว้ในคลังสาธารณะจะเปิดเผยตัวผู้เล่น ข้อมูลที่ออกจากเครื่องมีเพียงชื่อผู้นำ ชื่อรัฐ สี ธง และรหัสแบบแฮช
- **ความไว้ใจ** ระบบออกแบบสำหรับเล่นกับเพื่อน ทุกเครื่องถือสถานะเกมเต็ม คนที่เปิด devtools จึงดูลำดับกองทหารของคนอื่นได้ และบันทึกหอเกียรติยศปลอมแปลงได้ เจ้าของคลังลบรายการที่ไม่ต้องการออกจาก `data/hall-of-fame.json` ได้ตลอด
- **โดเมนของตัวเอง** ถ้าไม่ได้ใช้ที่อยู่ `github.io` ให้บอกเกมว่าคลังชื่ออะไร ด้วย `<meta name="fed-repo" content="ชื่อผู้ใช้/ชื่อคลัง">` และถ้า branch หลักไม่ได้ชื่อ `main` ให้เพิ่ม `<meta name="fed-branch" content="ชื่อ branch">`
- **เกมเดี่ยวบันทึกเองอัตโนมัติ** ปิดหน้าไปกลางเกมแล้วกลับมากด **เล่นต่อ** ในเมนูได้ ระบบเล่นคำตอบที่บันทึกไว้ย้อนจนถึงจุดเดิม
