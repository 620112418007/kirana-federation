กลับไปหน้าเกม

นโยบายความเป็นส่วนตัว

สหพันธรัฐแห่งคีรันนา · ปรับปรุงล่าสุด 10 พฤศจิกายน 2026

หน้าเกมนี้เป็นเว็บนิ่งบน GitHub Pages ผู้ทำเกมไม่มีเซิร์ฟเวอร์ของตัวเอง ข้อมูลส่วนใหญ่จึงอยู่ในเบราว์เซอร์ของผู้เล่น หน้านี้อธิบายว่าเกมใช้ข้อมูลอะไร ส่งไปที่ไหน และลบได้อย่างไร

1. การลงชื่อเข้าใช้ด้วย Google

ผู้เล่นลงชื่อเข้าใช้ Google เพื่อให้เกมบันทึกเกมและโปรไฟล์แยกตามผู้เล่น และให้ชัยชนะเข้าหอเกียรติยศได้ ไม่ลงชื่อก็เล่นได้ทุกโหมด เมื่อลงชื่อ Google ส่งโทเค็นยืนยันตัวตนให้หน้าเกม ในโทเค็นมีรหัสบัญชี ชื่อ อีเมล และลิงก์รูปโปรไฟล์ เกมใช้เพียงสามอย่าง คือรหัสบัญชี (แปลงเป็นแฮชก่อนเก็บ) ชื่อต้น และลิงก์รูปโปรไฟล์ เกมไม่อ่านและไม่เก็บอีเมล และไม่ขอสิทธิ์เข้าถึงข้อมูลอื่นในบัญชี Google

2. ข้อมูลที่เก็บในเบราว์เซอร์ของผู้เล่น

เกมเก็บข้อมูลไว้ในพื้นที่เก็บข้อมูลของเบราว์เซอร์ (localStorage และ sessionStorage) ได้แก่ แฮชรหัสบัญชี ชื่อต้น ลิงก์รูปโปรไฟล์ โปรไฟล์ผู้นำ (ชื่อผู้นำ ชื่อรัฐ สี ธง คำนำหน้า และบุคลิก) เกมที่บันทึกไว้ การตั้งค่า และรหัสสุ่มของเบราว์เซอร์ที่ใช้กับสถิติการเล่นในหัวข้อ 5 ข้อมูลชุดนี้อยู่ในเครื่องของผู้เล่น ผู้ทำเกมได้รับเฉพาะส่วนที่หัวข้อ 4 และ 5 บอกไว้ เกมไม่ใช้คุกกี้

3. การเล่นออนไลน์และรายชื่อผู้เล่นออนไลน์

เพื่อให้ผู้เล่นเจอกัน เบราว์เซอร์ต่อรีเลย์ Nostr สาธารณะ แล้วต่อถึงกันโดยตรงด้วย WebRTC ผ่านเซิร์ฟเวอร์ STUN ของ Google และ Cloudflare (และเซิร์ฟเวอร์ TURN ถ้าเจ้าของเกมตั้งไว้) การต่อตรงทำให้เครื่องที่เชื่อมกันเห็นที่อยู่เครือข่าย (IP) ของกันและกัน และรีเลย์เห็นการเชื่อมต่อของผู้เล่น

ข้อมูลที่ส่งถึงผู้เล่นคนอื่นมีชื่อผู้นำ ชื่อรัฐ สี ธง รหัสผู้เล่นแบบแฮช สิ่งที่กำลังทำในหน้าเกม การเดินในเกม และข้อความแชทในห้อง ผู้เล่นปิดการแสดงตัวในรายชื่อผู้เล่นออนไลน์ได้ที่ ตั้งค่า > แสดงตัวว่าออนไลน์

4. หอเกียรติยศและลานความคิดเห็น

เมื่อผู้เล่นที่ลงชื่อเข้าใช้ชนะ ผลเกม (ชื่อผู้นำ ชื่อรัฐ คะแนน จำนวนการ์ด และสายการเล่น) ถูกส่งให้ผู้เล่นที่ออนไลน์อยู่ ถ้าเจ้าของเกมตั้งหอเกียรติยศอัตโนมัติไว้ (Google Sheet กับ Apps Script) หน้าเกมส่งโทเค็นการลงชื่อให้สคริปต์ของเจ้าของเกมหนึ่งครั้ง สคริปต์ตรวจโทเค็นกับ Google แล้วเก็บเพียงแฮชของรหัสบัญชีกับผลเกม ไม่เก็บอีเมล

ความคิดเห็นที่ส่งจากหน้าเกมไปที่สคริปต์เดียวกัน สคริปต์เก็บความคิดเห็นพร้อมแฮชของรหัสบัญชี และแสดงชื่อผู้นำ ชื่อรัฐ ข้อความ และดาวให้ทุกคนที่เปิดลานความคิดเห็น ผู้พัฒนาลบรายชื่อในหอเกียรติยศหรือความคิดเห็นออกได้

ผลที่ส่งเข้าหอเกียรติยศผ่าน GitHub และความคิดเห็นที่เคยส่งผ่าน GitHub เป็นข้อมูลสาธารณะในคลังของเกม และผูกกับบัญชี GitHub ของผู้ส่ง

5. สถิติการเล่น

เมื่อเจ้าของเกมตั้งสคริปต์ข้างต้นไว้ หน้าเกมส่งสถิติการเล่นให้สคริปต์ เพื่อให้ผู้พัฒนารู้ว่าวันหนึ่งมีคนเข้ากี่คน เล่นจบกี่เกม และเกมไปติดหรือยากตรงไหน ข้อมูลที่ส่งมีดังนี้

  • จำนวนคนเข้าต่อวัน: วันละครั้งที่เปิดหน้าเกม หน้าเกมส่งสัญญาณให้สคริปต์บวกจำนวนคนเข้าของวันนั้น แยกสมาชิกกับผู้มาเยือน สคริปต์เก็บแค่ยอดรวมของแต่ละวัน ไม่เก็บรายการการเข้าชม รหัสสุ่มของเบราว์เซอร์ที่ส่งไปด้วยใช้กันนับซ้ำในวันเดียวกันแล้วไม่ถูกบันทึก
  • ทุกเกมที่เริ่ม จบ หรือออกกลางคัน: รหัสสุ่มของเบราว์เซอร์ โหมด ชุดกฎ จำนวนรัฐ ระดับ AI รอบที่ไปถึง เวลาที่เล่น คะแนนตอนจบ การ์ดวิจัยและการ์ดทหารที่แต่ละรัฐเลือก และบันทึกการเดินของเกม ซึ่งมีชื่อผู้นำ ชื่อรัฐ และทุกการตัดสินใจในเกม พอให้ผู้พัฒนาเล่นเกมนั้นซ้ำได้
  • ถ้าผู้เล่นลงชื่อเข้าใช้ สคริปต์เติมแฮชของรหัสบัญชี (ตัวเดียวกับที่ใช้ในหอเกียรติยศ) เพื่อนับว่าเป็นสมาชิก

สถิติไม่มีอีเมล ไม่มีชื่อบัญชี Google และไม่มีข้อความแชท สคริปต์ไม่เห็นที่อยู่ IP ของผู้เล่น ข้อมูลอยู่ใน Google Sheet ของเจ้าของเกม อ่านได้เฉพาะเจ้าของเกมและหน้าสถิติบนเครื่องผู้พัฒนา ไม่มีที่อยู่สาธารณะใดเปิดให้อ่าน และสคริปต์ลบแถวที่เก่ากว่า 1 ปีออกเอง

ปิดการส่งสถิติได้ที่ ตั้งค่า > ส่งสถิติการเล่น และถ้าเบราว์เซอร์ส่งสัญญาณ Global Privacy Control หรือ Do Not Track เกมจะไม่ส่งสถิติเลย

6. บริการภายนอกที่หน้าเกมติดต่อ

  • Google: การลงชื่อเข้าใช้ และไฟล์ฟอนต์จาก Google Fonts
  • GitHub: โฮสต์หน้าเกม และไฟล์บันทึกหอเกียรติยศที่อ่านจาก raw.githubusercontent.com
  • รีเลย์ Nostr และเซิร์ฟเวอร์ STUN: ใช้เมื่อเล่นออนไลน์และเมื่อแสดงรายชื่อผู้เล่นออนไลน์
  • Google Apps Script ของเจ้าของเกม: หอเกียรติยศ ลานความคิดเห็น และสถิติการเล่น

ผู้ให้บริการเหล่านี้อาจบันทึกที่อยู่ IP และข้อมูลการเชื่อมต่อตามนโยบายของแต่ละราย

7. สิ่งที่เกมไม่ทำ

เกมไม่มีโฆษณา ไม่ใช้บริการวิเคราะห์หรือติดตามของบุคคลที่สาม และไม่ขายหรือส่งต่อข้อมูลผู้ใช้ สถิติการเล่นในหัวข้อ 5 อยู่กับเจ้าของเกมเท่านั้น การใช้ข้อมูลที่ได้จาก Google API เป็นไปตาม Google API Services User Data Policy รวมถึงข้อกำหนด Limited Use

8. การลบข้อมูล

ออกจากระบบได้จากปุ่มในหน้าเกม ลบข้อมูลทั้งหมดในเครื่องได้ด้วยการล้างข้อมูลของเว็บไซต์นี้ในการตั้งค่าเบราว์เซอร์ และถอนสิทธิ์ที่ให้เกมไว้ได้ที่ myaccount.google.com/connections ถ้าต้องการให้ลบผลในหอเกียรติยศ ความคิดเห็น หรือสถิติการเล่นของคุณ แจ้งได้ที่หน้า Issues ของคลังเกม สำหรับสถิติ ให้บอกรหัสเบราว์เซอร์ที่หน้า ตั้งค่า แสดงไว้ การล้างข้อมูลของเว็บไซต์ในเบราว์เซอร์ทำให้ได้รหัสสุ่มใหม่

9. ติดต่อ

ถามหรือแจ้งเรื่องความเป็นส่วนตัวได้ที่ หน้า Issues ของคลังเกมบน GitHub ถ้านโยบายนี้เปลี่ยน วันที่ปรับปรุงด้านบนจะเปลี่ยนตาม
